AUTOAGENDA V1.2 — EDITAR E EXCLUIR

Esta versão corrige exatamente os pontos solicitados:

ALUNOS
- botão Editar
- alterar nome, WhatsApp, e-mail, categoria, aulas contratadas, aulas realizadas e observações
- botão Excluir
- exclusão lógica do aluno para preservar aulas antigas

AGENDA
- botão Alterar em cada aula
- alterar data
- alterar horário
- alterar duração
- alterar aluno, instrutor, veículo, local, status e observações
- mantém verificação de conflito de horário
- botão Excluir aula definitivamente

COMO ATUALIZAR NO GITHUB
1. Extraia este ZIP.
2. No repositório AutoAgenda, substitua estes arquivos:
   - server.js
   - public/index.html
   - public/app.js
   - public/style.css
3. Faça Commit changes.
4. O Render fará novo deploy automaticamente.
5. Se não fizer, abra Render > AutoAgenda > Manual Deploy > Deploy latest commit.

NÃO ALTERE:
- DATABASE_URL
- NODE_ENV
- banco mau-mau-ranking

TESTE
1. Abra AutoAgenda > Alunos.
2. Clique Editar em um aluno e salve.
3. Atualize F5 e confira se a alteração permaneceu.
4. Clique Excluir em um aluno e confirme.
5. Abra Agenda, escolha uma data.
6. Clique Alterar em uma aula, mude o horário e salve.
7. Atualize F5.
8. Clique Excluir em uma aula e confirme.

OBSERVAÇÃO
O aluno excluído deixa de aparecer na lista, mas suas aulas históricas permanecem no banco.
A exclusão de aula é definitiva.
