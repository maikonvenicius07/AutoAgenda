CORREÇÕES IMPORTANTES
1. Plano automático não ultrapassa o saldo de aulas do aluno.
2. Aulas antigas que ficaram como AGENDADA não reduzem indevidamente o saldo futuro.
3. Corrigida a soma entre aulas realizadas antes do AutoAgenda e aulas realizadas dentro do sistema.
4. Excluir aluno encerra planos e cancela futuras aulas, mantendo histórico.
5. Alterar uma série atualiza os dias do plano e preserva corretamente aulas simples/duplas.
6. Conflitos consideram somente aulas que ocupam agenda.
7. Domingo pode ser utilizado nos planos.
8. schema.sql foi corrigido para o schema autoagenda.
9. Reduzido problema de navegador mostrando versão antiga após deploy.
10. Proteção opcional por usuário e senha.

COMO ATUALIZAR NO GITHUB
1. Faça backup do ZIP atual do projeto.
2. Extraia AutoAgenda_V1_4_Revisado.zip.
3. Substitua o conteúdo do repositório pelos arquivos desta versão.
4. Faça Commit changes.
5. Aguarde o deploy do Render.
6. Abra o sistema e pressione Ctrl + F5 uma vez.

NÃO MUDE
- DATABASE_URL existente.
- APP_TIMEZONE pode permanecer como America/Porto_Velho para uso em Rondônia.
- O banco compartilhado apenas por causa desta atualização.

SEGURANÇA RECOMENDADA
No Render > AutoAgenda > Environment, crie:
AUTOAGENDA_USER = um usuário de sua escolha
AUTOAGENDA_PASSWORD = uma senha forte

Depois salve e faça novo deploy. O navegador passará a solicitar usuário e senha.

O server.js continua migrando o banco automaticamente. Não é necessário executar SQL manualmente.
