# Documentação do AutoAgenda

A documentação foi organizada para manter a raiz do projeto limpa e reduzir o risco de usar arquivos antigos por engano.

- `historico/` — checklists, relatórios de testes, relatórios de versões e notas históricas.
- `operacao/` — procedimentos operacionais, como automações e plano de backup.
- `planejamento/` — análise atual e próximas melhorias.

Os arquivos necessários para executar o AutoAgenda permanecem na raiz e nas pastas `public/`, `sql/`, `scripts/` e `infrastructure/`.
